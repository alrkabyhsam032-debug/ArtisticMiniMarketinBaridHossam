# نسخة Mini Market الفنية للعمل دون إنترنت على Windows

هذه النسخة تشغّل الواجهة والـAPI وقاعدة البيانات على نفس جهاز Windows:

- لا تحتاج Neon أو MongoDB أو Google Drive أثناء التشغيل.
- تحفظ البيانات بشكل دائم في `windows\data\market_db.json`.
- تفتح النظام على `http://127.0.0.1:8080`.
- الواجهة المبنية موجودة داخل `windows\frontend`، لذلك لا يحتاج التشغيل اليومي إلى Node أو الإنترنت.
- يمكن نسخ مجلد المشروع كاملًا إلى جهاز آخر، مع إبقاء مجلد `windows\data` للبيانات.

## المتطلبات

يجب تثبيت Python 3.11 أو أحدث مرة واحدة على الجهاز. بعد تثبيت الاعتمادات يمكن تشغيل النظام بدون إنترنت.

## التثبيت لأول مرة

افتح PowerShell داخل مجلد المشروع وشغّل:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\windows\install-offline.ps1
```

إذا كان مجلد `windows\wheels` موجودًا، سيستخدمه التثبيت دون الإنترنت. وإذا لم يكن موجودًا، يحتاج التثبيت الأول إلى الإنترنت لتنزيل الحزم. بعد اكتمال التثبيت، لا يحتاج التشغيل اليومي إلى الإنترنت.

## التشغيل

انقر مرتين على `windows\start-offline.bat`. ستفتح المتصفح تلقائيًا بعد ثوانٍ.

لإيقاف الخادم اضغط `Ctrl+C` في نافذة التشغيل أو شغّل `windows\stop-offline.bat`.

## الحسابات الأولية

- المدير: `admin` / `Admin@2026`
- المشرف: `manager` / `Manager@2026`
- الكاشير: `cashier` / `Cashier@2026`

غيّر كلمات المرور من داخل النظام قبل الاستخدام الفعلي.

## النسخ الاحتياطي والنقل

انسخ `windows\data\market_db.json` مع مجلد `windows\data\backups` إلى وسيلة آمنة. لا ترفع ملف قاعدة البيانات إلى GitHub لأنه قد يحتوي بيانات العملاء والمبيعات.
